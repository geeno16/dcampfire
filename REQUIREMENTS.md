# Сопоставление с требованиями

Сверено с `Требования_DС-1.docx`, `HTTP API описание.docx`, мобильным отчётом и макетами экрана из исходного архива. Здесь описано состояние локальной версии; пункты с измеримыми внешними условиями требуют отдельного испытания.

| Требование | Реализация / проверка |
| --- | --- |
| Регистрация, шестизначный код 10 минут и 5 попыток, повтор через 60 секунд; вход без кода | `backend/src/auth`, `backend/src/email_code`, `backend/test/test_auth.py`; экраны регистрации, подтверждения и входа в `android/app/src/main/kotlin/ru/dcampfire/ui/AuthScreens.kt`. Коды появляются в Mailpit. |
| Уникальный псевдоним 3–20, пароль от 8 символов, согласие | Схемы и проверки сервера в `backend/src/auth/schema.py`, `backend/src/user/schema.py`, форма Android; пароль хранится в виде Argon2-хеша. |
| Профиль: аватар JPEG/PNG до 5 МБ с заменой, имя, пароль, до 10 тем, удаление аккаунта | `backend/src/user`, `backend/test/test_profile.py`, `android/app/src/main/kotlin/ru/dcampfire/ui/SettingsScreens.kt`. Доступ к аватарам требует токен. |
| Костёр: название 3–40, 8 цветов, до 5 тем, альбом Яндекс Музыки, открытость; до 5 участников и до 5 костров на пользователя | `backend/src/bonfire`, `backend/src/album`, `backend/src/membership`; формы и чат Android. Тесты `test_bonfire.py`, `test_membership.py`, `test_concurrency.py`, `test_album.py`. |
| Подбор открытых костров со свободными местами по общим темам; приглашения и действия хозяина | `backend/src/bonfire/repository.py`, `backend/src/membership`; две вкладки главного экрана, список участников, приглашения. |
| Текст до 1000 символов, глобальная пауза 10 секунд, история с курсорами, WebSocket и восстановление после переподключения | `backend/src/message`, `backend/src/realtime`; `android/api/src/main/kotlin/ru/dcampfire/client/RealtimeClient.kt` и `CampfireViewModel.kt`; `test_message.py`, `test_realtime.py`. |
| Русский тёмный интерфейс, портретный Android 8+, загрузка, ошибки, сохранённые данные без сети | `android/app/src/main`, `minSdk=26`; зашифрованный кеш `data/SecureStore.kt`, Compose-экраны и сообщения об ошибках. Визуальное сопоставление с PDF требует проверки на устройстве. |
| Доставка 95% сообщений за ≤3 секунды, первый экран ≤5 секунд, контраст 4,5:1 | Архитектура поддерживает быструю доставку и кеш для старта; измерения на целевых устройствах и сетях ещё не проводились. Эти численные показатели не подтверждены. |
| Хранение персональных данных в РФ и эксплуатационная безопасность | Локальная сборка хранит данные на компьютере пользователя и не определяет страну размещения. Для публичного сервиса потребуется отдельное размещение в РФ, TLS, реальная почта и оформление обработки данных. |

Включённые серверные тесты проверяют запреты на несанкционированный доступ и превышение лимитов, конкурентное вступление, отмену приглашений, пагинацию сообщений, события WebSocket и удаление аккаунта. Для проверки полного пользовательского пути следуйте шагам в README и используйте два аккаунта.

Дополнительно выполнен сквозной запуск с настоящими PostgreSQL, SMTP, HTTP и WebSocket: регистрация и подтверждение почты двух пользователей, вступление, доставка сообщения, чтение истории и отказ в повторной отправке во время паузы прошли. Проверки численных показателей производительности и страны размещения остаются открытыми.
