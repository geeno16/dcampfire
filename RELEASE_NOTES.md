# Проверки версии 0.1.1

Дата сборки: 18 ноября 2026 г. В `release/app-debug.apk` лежит устанавливаемая отладочная версия для Android 8.0+.

Исправления 0.1.1: основной текст теперь получает светлый цвет на тёмном фоне, как в макетах; загрузка рекомендаций использует допустимый размер страницы 50 и больше не блокирует список собственных костров при ошибке.

| Проверка | Результат |
| --- | --- |
| Сервер: PostgreSQL и pytest | 112 тестов пройдены, включая конкурентные ограничения и проверку изображений. |
| Клиент API: JUnit/MockWebServer | 7 тестов пройдены; проверены токен, 64-битные ID, частичное обновление, ошибка паузы, история и WebSocket-адрес. |
| Gradle `:app:assembleDebug` | Успешно. APK собран с `minSdk=26`, `targetSdk=37`. |
| `spotlessCheck`, `:app:detekt`, `:app:lintDebug` | Успешно. |
| Подпись APK | `apksigner verify` подтвердил подпись APK v2. |
| Конфигурация Docker Compose | `config --quiet` прошла для обычного и тестового профилей. |
| Сквозной сценарий | Подняты локальные PostgreSQL, SMTP и FastAPI; проверены регистрация двух аккаунтов, создание костра и его появление в «Моих кострах», допустимый запрос рекомендаций, вступление, событие WebSocket, REST-история и 10-секундная пауза. |

В этом рабочем окружении нет Docker Engine и Android-эмулятора, поэтому контейнеры и сами экраны на устройстве здесь не запускались. После распаковки следуйте README и проверьте полный интерфейс в Android Studio. Показатели 95% доставки за 3 секунды, старта за 5 секунд и контраста 4,5:1 не измерялись на целевых устройствах. Хранение персональных данных в РФ зависит от будущего места размещения; текущая версия рассчитана на локальный сервер.
